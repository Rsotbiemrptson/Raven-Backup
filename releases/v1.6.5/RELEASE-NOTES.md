# Raven Backup 1.6.5

- Match Raven Gamepad’s Advanced button backgrounds, with two buttons per row and shorter descriptions.
- Center the three-dot icon within its button and prevent Android button tinting from changing the shared Raven colors.
- Keep About focused on Raven Backup by removing the Raven family paragraph.

Built with the existing release signing identity. The final APK matches the build tested on the Odin 2 byte for byte. Dark/light Advanced layouts, shared background colors, menu alignment and About were verified on-device. All six host suites and the FirmwareCheck integration harness passed. Backup/restore and guided-setup behavior are unchanged; no personal app-data operations were performed for this patch.

Install over an existing Raven Backup to retain settings and permissions. GPL-3.0-only. Actual Odin 3 transfer, Android 15 execution, Retroid hardware and Enforcing SELinux remain unverified.
