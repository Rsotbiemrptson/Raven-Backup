# Raven Backup 1.6.1

Corrects the icon’s uneven, partially transparent dark background in both the app and GitHub page. The tile is now solid **#1F2228**, with the original rounded outline, raven, box and green arrow retained.

This is an icon-only patch: app classes and the bundled setup helper are byte-identical to 1.6.0. The signed update was installed and visually checked on the Odin 2, and pixel comparisons verified the original artwork colors, outline and packaged icon. Update over an existing installation to retain settings and permissions.

Fresh installs still require guided setup. Compatibility and restore limitations are unchanged; actual Odin 3/Retroid hardware and Enforcing SELinux remain unverified. GPL-3.0-only; matching source and documentation are included.
