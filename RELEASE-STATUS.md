# Current release

Raven Backup **1.8.0**, version code 38, package `dev.raven.backup`.

Adds optional authenticated password encryption, off-by-default Remember password with schedule reminders, verified newest-N retention, dated full-verification status, detailed progress and restore folder/space previews. Existing plaintext backups remain readable; encrypted `.rbk` files require 1.8.0 or newer. Backups remain independent full archives. The Odin OEM backend passed exact-build Odin 3 tests; standard su is an explicit option for already-rooted devices but still needs hardware acceptance. See [Testing](docs/TESTING.md) and [Encryption](docs/ENCRYPTION.md).
